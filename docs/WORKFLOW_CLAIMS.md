# Workflow claims

This contract records ordered user-visible workflow claims and their authority, semantic tests,
bounded evidence and limitations. Planned behavior cannot be promoted by screenshots or file
presence. Optional visual assets are digest- and source-bound, require dimensions and an
accessibility description, and never establish usability or visual approval. AWQ performs no
capture, UI execution, localization validation or publication.

Claims contain each lifecycle stage exactly once and in canonical order: goal, preconditions,
automatic actions, human decisions, outcomes, failures and recovery. Exactly one authored source is
authoritative for each claim; generated and derived documents retain explicit source lineage and a
generator digest where applicable. Superseded sources cannot remain authoritative.

Visual evidence is optional and consumer-owned. When present, every asset is linked bidirectionally
to one non-planned claim, its exact current source revision, reviewed capture environment, review
chronology, accessibility description and API, ABI, form-factor, locale and font-scale dimensions.
Those dimension values are opaque consumer declarations, not platform pins. An optional baseline
uses deterministic digest equality; equality is not evidence of accessibility, localization
correctness, visual approval or usability.
